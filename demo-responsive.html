🎯 响应式固定导航栏演示

这是一个完全响应式的固定左侧导航栏系统，实现了你所有的需求规格。

核心特性

  • 始终固定在页面左侧，不受页面滚动影响
  • 适配所有屏幕尺寸（桌面/平板/移动端）
  • 保证导航栏内容完整显示
  • 不受其他元素布局、屏幕缩放影响
  • 响应式调整布局形态（桌面端展开、移动端可折叠）
  • 高 z-index 确保不被其他元素遮挡
  • 支持键盘导航和无障碍访问
  • 状态持久化保存

📱 响应式适配规则

桌面端 (≥1200px)

宽度: 260px | 完全展开
显示图标+文字，横向排列

平板端 (768-1199px)

宽度: 220px | 紧凑展开
显示图标+精简文字

移动端 (<768px)

宽度: 60px | 可折叠
仅显示图标，可展开

⚙️ 技术实现

CSS 核心特性

  • position: fixed 固定定位
  • z-index: 9999 高层级显示
  • transform: none 禁用缩放变形
  • overflow-y: auto 内容溢出滚动
  • transition 平滑动画过渡
  • 媒体查询响应式断点

JavaScript 控制逻辑

  • 窗口大小变化监听
  • 触摸和鼠标事件处理
  • 键盘导航支持
  • 状态持久化存储
  • 防抖优化性能
  • 无障碍访问支持

🔧 使用方法

在你的项目中集成这个响应式导航栏非常简单：

<!-- 1. 引入CSS文件 -->
<link rel="stylesheet" href="responsive-sidebar.css">

<!-- 2. 引入JavaScript文件 -->
<script src="responsive-sidebar.js"></script>

<!-- 3. 创建主内容区域 -->
<div class="main-content">
  <!-- 你的页面内容 -->
</div>

<!-- 导航栏会自动创建和初始化 -->
