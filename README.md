# AI MV 生成平台 - 功能说明
该项目是一款基于 AI 技术的 MV 生成平台，用户可通过选择创作风格、音乐素材，最终由 AI 自动生成匹配的 MV 视频，核心包含风格选择、音乐选择、AI 创作三大核心页面，支持选择偏好存储、页面导航及创作内容验证等功能。

## 页面功能说明
### 1. index.html（风格选择页面）
| 功能点 | 状态 | 描述 |
|--------|------|------|
| 风格卡片选择 | ✅ 已实现 | 点击 SINGING（演唱风）/STORYTELLING（叙事风）/AUTOMATIC（自动适配）风格卡片，选定 MV 创作风格并跳转到音乐选择页面 |
| 跳过风格选择 | ✅ 已实现 | 点击"Skip"按钮，跳过风格选择直接进入音乐选择页面（AI 后续将默认使用 AUTOMATIC 风格生成 MV） |
| 风格本地存储 | ✅ 已实现 | 选中的风格信息保存到 localStorage，供后续音乐选择、AI 创作页面读取 |

### 2. music.html（音乐选择页面）
| 功能点 | 状态 | 描述 |
|--------|------|------|
| 风格信息展示 | ✅ 已实现 | 页面顶部展示从风格选择页传递的创作风格（如「当前风格：叙事风」），让用户确认选择 |
| 音乐项目选择 | ✅ 已实现 | 点击音乐列表项选定素材，自动跳转到 AI 创作页面（选定的音乐为 MV 核心配乐） |
| 选中状态反馈 | ✅ 已实现 | 选中的音乐项显示蓝色高亮边框/背景，直观反馈选中状态 |
| 跳过音乐选择 | ✅ 已实现 | 点击"Skip"按钮，跳过音乐选择直接进入创作页面（AI 将随机推荐热门音乐生成 MV） |
| 音乐本地存储 | ✅ 已实现 | 选中的音乐名称/ID 保存到 localStorage，供 AI 创作环节读取配乐素材 |

### 3. create.html（AI 创作页面）
| 功能点 | 状态 | 描述 |
|--------|------|------|
| 选择信息展示 | ✅ 已实现 | 页面显著位置展示「创作风格」「选定音乐」信息，支持用户核对素材 |
| 重新选择风格 | ✅ 已实现 | 点击风格标签（如「叙事风」），返回首页重新选择创作风格 |
| 重新选择音乐 | ✅ 已实现 | 点击音乐标签（如「所选音乐：XXX.mp3」），返回音乐选择页更换配乐素材 |
| AI 创作触发 | ✅ 已实现 | 在输入框填写 MV 额外创作要求（如画面风格、剧情关键词等），点击"Create"按钮启动 AI 生成 MV |
| Logo 首页跳转 | ✅ 已实现 | 点击页面 Logo，快速返回风格选择首页重新开始创作流程 |
| 输入内容验证 | ✅ 已实现 | 验证输入框非空，确保用户填写创作要求后再触发 AI 生成（避免无意义请求） |

## 交互流程
```
首页（index.html）
  ↙️ 选择风格（演唱/叙事/自动） / ↘️ 点击Skip跳过
音乐选择页面（music.html）
  ↙️ 选择音乐素材 / ↘️ 点击Skip跳过
AI 创作页面（create.html）
  ↳ 可点击风格标签返回首页重新选风格
  ↳ 可点击音乐标签返回音乐页重新选音乐
  ↳ 输入MV创作要求 → 点击Create按钮 → AI基于风格+音乐+创作要求生成MV
```

## 核心技术逻辑
- 页面导航：通过 `window.location.href` 实现页面间跳转，保证流程连贯性；
- 数据持久化：利用 `localStorage` 存储风格/音乐选择状态，实现跨页面数据共享；
- 交互反馈：通过 CSS 样式修改实现音乐选中状态的视觉提示；
- 创作验证：检查输入框内容是否为空，避免无创作要求的 AI 生成请求；
- AI 核心逻辑：创作页面点击 Create 后，前端将「风格+音乐+创作要求」参数传递给后端，由 AI 模型匹配音乐节奏、风格调性生成对应 MV 视频。
